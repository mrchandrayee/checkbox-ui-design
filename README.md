## Video content

The video title is **Checkbox UI Design**. It presents a dark navy/blue interface with a glowing blue heading, orange outer border and stacked rounded translucent cards. Each card has a numbered title, an interactive control, a label and a short description.

The ten styles appear in this order:

1. **Basic Modern Checkbox** — Enable notifications. Clean square checkbox with animated SVG tick and soft glow.
2. **Rounded Checkbox** — Receive updates. Circular checkbox with a growing center dot and focus ring.
3. **Glassmorphism Toggle Checkbox** — Auto backup. Translucent glass switch built using a checkbox input.
4. **Neumorphism Checkbox** — Dark mode preference. Soft inset/extruded effect for a neumorphic dashboard look.
5. **ON/OFF Toggle Checkbox** — Two-factor auth. Classic settings toggle with state label and sliding thumb.
6. **Animated Tick Checkbox** — Mark as completed. Tick is drawn using two animated pseudo-elements.
7. **3D Press Checkbox** — Confirm action. A tactile 3D button effect that “presses” down when checked.
8. **Gradient Checkbox** — Premium selected. Vibrant gradient fill with animated inner icon.
9. **Icon Checkbox** — Favorite this item. Uses an icon reveal instead of a standard check mark.
10. **Card Selection Checkbox** — Pro Design Package. Includes landing page UI, responsive components, and micro-interaction support. Great for pricing cards, selectable plans, or feature bundles.

## Run

1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Click/tap each checkbox or use Tab + Space on the keyboard.
4. Resize the browser to see the responsive layout.

No npm packages, build tools, or server required.

## Files

- `index.html` — all ten controls and labels
- `style.css` — full visual styling, focus states, responsive layout and transitions
- `script.js` — state label behavior for the ON/OFF toggle and selected-card state

## Extraction note

The video shows the rendered UI, not the full original source editor. The title, ten control names, labels and descriptions have been transcribed from the visible screen. The complete runnable HTML/CSS/JS implementation is recreated from the visual reference; it is not represented as the exact hidden original source.
